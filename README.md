# python-activity-based-learnings
Python Activity Based Learning Assignment - NRI College

## About
This repo contains 10 Python Case Studies implemented using only assigned syllabus:
Computational Thinking, Algorithms, Flowcharts, Variables, Data Types, Operators, Conditions, Loops, Strings, Lists, Nested Lists, Tuples, Tuple Operations and Unpacking.

## Activities Completed (10 Case Studies)

### 1. University Scholarship Allocation
- Logic: Aggregate >=450, Attendance >=75%, Income <=60000
- Concepts: Lists, Tuples, Unpacking, Loops, Ranking
- Code: `code/1_scholarship.py`

### 2. Progressive Electricity Billing
- Logic: Slab billing (0-100: Rs.5, 101-300: Rs.7, >300: Rs.10) + Fixed Charge + Surcharge
- Concepts: Conditions, Loops, Variables
- Code: `code/2_electricity.py`

### 3. Hospital Billing with Concessions
- Logic: Total = Consultation + Diagnostic + Treatment, 10% concession if >5000
- Code: `code/3_hospital.py`

### 4. Employee Payroll and Appraisal
- Logic: Gross = Basic + DA + HRA, Bonus based on performance
- Code: `code/4_payroll.py`

### 5. Retail Billing with GST and Discount
- Logic: Discount 10% if total>1000, GST 18%
- Concepts: Nested Lists, Tuple Unpacking
- Code: `code/7_retail.py`

### 6. Examination Result with Grace Marks
- Logic: Pass/Fail, Grace 5 marks if one subject 30-34
- Code: `code/11_exam.py`

### 7. Attendance Recovery Planning
- Logic: Calculate shortage and extra classes needed for 75%
- Code: `code/12_attendance.py`

### 8. ATM Transaction and Balance Update
- Logic: Deposit, Withdraw with minimum balance check
- Code: `code/13_atm.py`

### 9. Warehouse Inventory Classification
- Logic: ABC classification based on stock value
- Code: `code/14_inventory.py`

### 10. Campus Event Budget Planning
- Logic: Budget allocation and expense tracking
- Code: `code/10_event.py`
